# Type Garden

Una recreación interactiva y generativa inspirada en [Type Garden](https://type-garden.vercel.app/) por Akshat Agarwal. Conforme escribes, tallos, espinas, hojas y rosas florecen orgánicamente desde las letras.

## ✨ Características

- **Generación procedimental:**
  - Al escribir, las letras brotan tallos con flores y hojas.
  - La barra espaciadora (`Space`) corta los tallos con una eclosión terminal para iniciar una nueva palabra.
  - La tecla de retroceso (`Backspace`) marchita las flores con animación suave de desvanecimiento.
  - La tecla `Enter` limpia el jardín para comenzar de nuevo.
- **Tipografía elegante:**
  - *Playfair Display Bold* (Google Fonts) para las letras del jardín.
  - *DM Mono* para la interfaz de usuario y controles.
- **Interacción con el puntero:**
  - Las flores y letras se inclinan hacia el cursor o punto de contacto táctil.
  - Al hacer clic o doble clic aparecen mariposas revoloteando y puedes plantar rosas de regalo.
- **10 Paletas de color:**
  - Rose noir, Paper, Midnight, Citrus, Orchid, Moss, Tomato, Butter, Blush y Mono.
- **Estudio de Poster (1080 × 1080):**
  - Animaciones en bucle: *Breathe, Grow & wither, Typed, Gust, Reach, Scatter, Visitor*.
  - Exportación en video **MP4 / WebM**, fotogramas en **ZIP**, captura **PNG** y vector **SVG**.
- **Autocontenido:**
  - Un único archivo HTML con Canvas y JavaScript vanilla sin herramientas de construcción ni dependencias complejas.

## 🚀 Uso

Abre `index.html` directamente en tu navegador favorito.
